# CRN Typer - AUB

**[Download CRN Typer - AUB.zip](https://github.com/mechboi09/crn-typer-mac/raw/refs/heads/main/downloads/CRN%20Typer%20-%20AUB.zip)**

The ZIP contains only the app. It supports Apple Silicon and Intel Macs running macOS 12 or later.

## How to use

1. Extract **CRN Typer - AUB.zip**, move **CRN Typer - AUB.app** to Applications, then open it.
2. Enter up to **seven CRNs** in each of the four options.
3. Press **F1–F4** for the matching option. Some keyboards need **Fn/Globe + F1–F4**.
4. Review Summary, then press **Submit** yourself.

## First-time setup

If macOS says Apple cannot verify the app:

1. Try opening it once.
2. Go to **System Settings → Privacy & Security** and click **Open Anyway** under Security.
3. Confirm Open and enter your Mac login password if prompted.

Then enable **CRN Typer - AUB** under **Privacy & Security → Accessibility** and restart the app. Add it using **+** if it isn't listed. On macOS 12, use **System Preferences → Security & Privacy → Privacy → Accessibility**.

Only open a downloaded app you trust. [Apple's instructions](https://support.apple.com/en-us/102445)

## Editing

- Paste a list into a box to fill it and those below it. Separate CRNs with spaces, commas or new lines.
- Press **Command+A** or **Control+A** once to select one CRN, or **twice quickly** to select the column.
- Copy, Cut, Paste and Delete work on the selected column. Clearing returns to its first box.
- **Closing the app clears your CRNs.**

## Modes

**Fast is the default.** The compact black **Normal / Fast** switch sits below the options. The inactive label is gray and the white knob has a thin outline. Open **Tips** on the right for the mode notes.

| Normal | Fast |
| --- | --- |
| 200 ms | 1 ms |

The timing values are programmed pauses; the browser and macOS can affect actual speed. The app finishes at **Add to Summary**.

**Escape** cancels; switching applications also stops a run. Keep the correct browser tab and field focused, and review the result in Summary.
