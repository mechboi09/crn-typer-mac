## CRN Typer for Mac

Download **CRN-Typer-Mac-Universal.zip** below. Extract it, open the `package` folder, and move **CRN Typer.app** to Applications. A README is included.

- Four CRN lists with F1–F4 shortcuts.
- Normal (300 ms) and Fast (1 ms requested pauses).
- Escape cancellation and automatic stop when switching apps.
- Apple Silicon and Intel support on macOS 12 or later.

Grant Accessibility permission to let the app type into your browser. Some Mac keyboards need Fn/Globe with the function keys.

The app is locally signed, not Apple notarized. Actual Fast mode timing depends on the browser. It stops at Add to Summary and does not press registration Submit.
